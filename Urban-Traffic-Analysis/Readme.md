# Traffic Power BI Dashboard Project

This project contains a Power BI dashboard focused on analyzing and visualizing traffic data such as vehicle counts, congestion patterns, and trends.

## 📊 Dashboard File
- **Trafic Power BI Dashboard.pbix** — Main Power BI dashboard

## ✅ Requirements
- Power BI Desktop installed (latest recommended version)

## 🚀 How to Use
1. Download the `.pbix` file
2. Open using **Power BI Desktop**
3. Refresh visuals if needed
4. Explore insights and traffic trends

## 🛠️ Step-by-Step to Create Dashboard (How it was done)
1. **Data Collection**
   - Imported traffic datasets (example: vehicle type, time, road name, volume)
2. **Data Cleaning**
   - Removed duplicates & corrected data types
   - Handled missing values
3. **Data Modeling**
   - Created relationships between tables (if multiple sources used)
4. **Measures & Calculations**
   - Built DAX measures:
     - Total Traffic Volume
     - Peak Hour Traffic
     - Average Vehicle Count
5. **Dashboard Design**
   - Visuals used:
     - Line chart (traffic over time)
     - Bar chart (vehicle type comparison)
     - Map (traffic by area — if location field available)
     - KPIs for total counts & peak values
6. **Formatting & Filters**
   - Slicers added: Date, Location, Vehicle Category
   - Color theme applied for visibility
7. **Publishing / Sharing**
   - Dashboard exported/saved as `.pbix` for sharing
