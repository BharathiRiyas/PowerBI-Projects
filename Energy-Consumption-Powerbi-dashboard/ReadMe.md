# Energy Consumption Dashboard Project

This project includes a Power BI dashboard for analyzing and visualizing energy consumption metrics.

## 📊 Dashboard File
- Energy Consumptions Dashboard.pbix — Main Power BI dashboard

## ✅ Requirements
- Power BI Desktop installed on your system

## 🚀 How to Use
1. Download the `.pbix` file
2. Open it using **Power BI Desktop**
3. Explore the visuals and insights

## 📂 Project Structure
```
|-- Energy Consumptions Dashboard.pbix
|-- README.md
```

## ✨ Features
- Energy usage analytics
- Trends and consumption breakdown
- Interactive filters and visuals
