# ✈️ Airline Passenger Satisfaction Dashboard

## 📌 Project Overview  
This project is a **Power BI data analytics dashboard** that provides insights into **Airline Passenger Satisfaction**. The dashboard helps stakeholders understand key factors affecting passenger experience and highlights improvement opportunities in airline services.

## 🎯 Objective  
The primary goal of this analysis is to explore **what influences customer satisfaction** in the airline industry. It answers important questions like:

✅ Which service areas are performing well?  
✅ Which customer segments are most satisfied or dissatisfied?  
✅ How do factors like travel class, journey type, and age group impact satisfaction?  
✅ What improvements can enhance the passenger experience?

## 📊 Key Dashboard Features  
The dashboard includes the following analytical visuals:

- 🔹 Overall Satisfaction Score Overview  
- 🔹 Passenger Demographics (Age Group, Gender, Customer Type)  
- 🔹 Flight Service Analysis (Cleanliness, Inflight Wifi, Food & Beverage, Seat Comfort etc.)  
- 🔹 Class-wise Satisfaction (Economy, Business, Premium)  
- 🔹 Journey Type (Business/Personal) Insight  
- 🔹 Flight Delay Impact on Satisfaction  
- 🔹 Filters to drill down into specific customer segments

## 🧠 Insights Derived  

✔️ Business passengers show higher satisfaction compared to personal travelers  
✔️ Longer delays directly increase dissatisfaction  
✔️ Seat comfort and onboard services are major improvement areas  
✔️ Loyal customers (frequent flyers) show more positive feedback  

## 🏁 Conclusion  
This dashboard helps airlines **identify key improvement areas** to enhance overall customer experience and loyalty. It can be expanded with real-time operational data for continuous insights.
